# Check Cheats using the open source code from https://github.com/ABKAM2023/CS2-Check-Cheats
The plugin was rewrited and cleaned a little bit by deleting some useless stuff from it.
Added an Center Menu, using the https://github.com/T3Marius/T3Menu-API

# For installation you will need the T3Menu-API on server


# Configuration
Admin permission for using commands is "@admin/check", "@admin/uncheck"

You can edit the text/time/command/discordlog to execute in Config.yml
